# InfectedVariants

**Requires:** SPT 4.1.6, Fika 2.4.6 compatible (headless safe: nothing registers on a client that never opens the map screen, and nothing here swaps on the client). Hard dependency: MapVariants 1.1.0 or later (`com.lennoxp90.mapvariants`). Soft: FactoryClassic 1.2.0 or later (`com.lennoxp90.factoryclassic`; its Halloween 2026 variant is another infected map and is renamed here; without it nothing is renamed). Deliberately no `BepInDependency` on FactoryClassic: the plugin GUID is `com.krane.infectedvariants` so BepInEx (which loads in GUID order, dependencies first) runs it before FactoryClassic. Needs the server mod `InfectedVariants4Server` (it decides which maps are offered), and PPES with Halloween and the 2026 outbreak on and `labInfectedOnly` off. MapVariants' `maps.json` must have no entry for any map offered here (the plugin logs an error and skips such a map). ManimalInterchange / ManimalLighthouse (`com.manimal.interchange` / `com.manimal.lighthouse`) are needed on the client only if the server has them: their patches stay active for both choices.

## What
Adds an Infected choice to the MapVariants map prompt on every stock raidable map the server enables: Customs, Woods, Shoreline, Interchange, Lighthouse, Reserve, Streets of Tarkov, Ground Zero (Sandbox and Sandbox_high are one choice) and Labs. Unmodded maps offer "Normal map" (default) / Infected ("Zombies everywhere"); maps with a backport mod (Interchange and Lighthouse with Manimal) offer "Manimal rework" (default) / Infected. MapVariants' "original" tile is never shown (the server also serves any "original" answer as the backport). The map-screen infection badge is 0 everywhere (server). Zombies spawn only on an Infected choice and on Factory's Infected choice. FactoryClassic's "Halloween 2026" variant is renamed to "Infected" everywhere players see it (prompt tile, loading screen label, F12 `Factory` > `DefaultSelection`; a stored "Halloween 2026" default becomes "Infected").

## Why
The server mod keeps the Halloween outbreak off every map by default; this registers the choices on the client so you can pick them per raid.

## How
The plugin asks the server (`GET /infectedvariants/maps`) which maps to offer, when the map screen is shown (retried on each showing, up to 10 times, until the server answers; one synchronous request per try), and registers them with MapVariants then, before its Next-button prompt (logged as `Registered with MapVariants: ...`). A backport-based map is registered as a MapVariants provider, so the backport mod's own patches stay live for both choices; two Harmony prefixes on MapVariants' prompt (`MapVariantPrompt.ShowChoice` notes the map by location id, `MapChoiceWindow.Show` re-invokes itself with the original tile dropped and the subtitles replaced; if they cannot be installed a warning is logged and the tile shows). `Prompt hooks installed` is logged once they are in. Ground Zero's two ids are one choice; a mixed-level group that the game moves from Sandbox to Sandbox_high after the prompt gets the server's answer for Sandbox_high (Vanilla unless someone chose it there).

The rename is a Harmony prefix on MapVariants' `Maps.RegisterVariants` that rewrites FactoryClassic's variant name in the call before MapVariants binds the F12 list from it (so a saved `Infected` default persists, and a stored `Halloween 2026` value is migrated). It needs this plugin to load before FactoryClassic; if FactoryClassic is already loaded a warning is logged and the old name stays. FactoryClassic's files are untouched.

## Settings
None here. The choice and its default are MapVariants' own (F12, one section per map); the infection level and the list of enabled maps are in the server mod's `config.json`.
